## 1. Продукт

**SNIN Relay V2** — Nostr relay с 5 прорывными технологиями, которых нет ни у кого:

| # | Технология | Уникальность |
|---|-----------|-------------|
| 1 | **SSE Transport** | Nostr без WebSocket — работает через Cloudflare, прокси, AWS. 0 аналогов |
| 2 | **IPFS PubSub Mesh** | События живут в IPFS сети (16 пиров). Если relay умирает — данные не теряются. 0 аналогов |
| 3 | **Mass Pulse** | Живая карта 5027 Nostr relay. Проверка каждые 10 мин. 0 аналогов на Python |
| 4 | **Adaptive Fanout v4** | Умная маршрутизация по latency + NIP-65. Экономия 30% трафика. 0 аналогов |
| 5 | **NIP-26 Delegation + Agent Registry** | 79 AI агентов подписывают от имени людей. 0 аналогов |

**Подтверждено:** GitHub поиск 6 мая 2026 — 0 результатов по `nostr+ipfs+pubsub`, `nostr+sse`, `nostr+ipfs+python`.

### 2.2 SaaS (долгий горизонт — 2+ года)

**Модель:** Relay-as-a-Service. Продажа приватных relay с SSE транспортом.

**Ниша:** AI компании — их агенты не могут использовать WSS в serverless (AWS Lambda, Cloudflare Workers). SSE решает эту проблему.

| Клиент | Проблема | Продукт | Цена/мес |
|--------|---------|---------|---------|
| AI компании | Агентам нужен Nostr, WSS не работает в serverless | SSE relay + Agent Registry | $100–500 |
| DAO проекты | Нужна платформа для голосования + чаты | DAO-governed relay | $50–200 |
| Разработчики | Хотят свой relay без администрирования | Managed relay "под ключ" | $20–50 |
| Nostr комьюнити | Не хотят зависеть от публичных relay | Приватный relay для группы | $10–20 |

**Прогноз доходов:**

| Сценарий | Клиентов | Средний чек | Доход/мес | Когда |
|----------|---------|------------|-----------|-------|
| Минимум | 10 | $50 | $500 | 3 мес |
| Реалистично | 50 | $100 | $5,000 | 12 мес |
| Хорошо | 200 | $150 | $30,000 | 24 мес |

### 2.3 Патент — НЕ РЕКОМЕНДУЕТСЯ

**Почему нет:**
- Патент в США стоит $5k–$15k — весь грант уйдёт на юристов
- OpenSats и HRF дают гранты на open-source. Патент конфликтует с их условиями
- Чтобы заработать на патенте, нужно судиться — это $100k+
- SSE для Nostr — это метод, запатентовать "идею" почти невозможно

**Когда стоит пересмотреть:** если SaaS вырастет до $100k+ в год и появятся конкуренты, которые копируют технологию. Тогда патент становится защитным, а не спекулятивным.

## 3. Сценарий конкуренции грантодателей

### 3.1 Принцип

Каждая заявка содержит фразу:
> *"This project is also under evaluation by [другой фонд]. A grant from [текущий фонд] would complement their support and enable [специфическая часть]."*

Это создаёт:
- **FOMO** — фонды не хотят упустить проект
- **Разделение ответственности** — каждый финансирует свою часть
- **Социальное доказательство** — если другие уже проверили, проект надёжный
